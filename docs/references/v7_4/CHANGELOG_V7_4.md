# Ivideon Recruit v7.4 — финальная верстка

## Обновлён рабочий маршрут

Единый маршрут на главной и в полном представлении теперь состоит из 10 этапов:

1. Получена новая вакансия
2. Провожу бриф
3. Ищу кандидатов
4. Провожу HR-интервью
5. Провожу совместное интервью с заказчиком
6. Показываю кандидата заказчику
7. Согласовываю оффер
8. Делаю оффер кандидату
9. Готовлю выход сотрудника
10. Сопровождаю адаптацию

## Согласование оффера

- вход в процесс начинается только после общего решения всех участников найма;
- участники включают рекрутера, заказчика, Руководителя подбора, HRBP, директора по персоналу, генерального директора, КДП/кадры и других участников оценки;
- возвращена подробная инструкция по письму директору по персоналу;
- сохранены адресаты, тема, обязательные поля и правила вложений;
- добавлен отдельный шаг финального согласования генерального директора;
- этап завершается только после подтверждений директора по персоналу и генерального директора;
- сценарий выхода за вилку отделён от стандартного согласования.

## Оффер кандидату

Добавлен отдельный этап с:

- устной презентацией предложения;
- привязкой оффера к мотивации кандидата;
- правилами обсуждения условий и сомнений;
- SLA коммуникации;
- работой с контроффером;
- действиями при принятии и отказе;
- фиксацией результата в Huntflow;
- отдельным чек-листом.

## Навигация и структура

- главная и полный маршрут используют один и тот же массив этапов;
- совместное интервью и показ кандидата заказчику разведены;
- согласование оффера и презентация кандидату разведены;
- подготовка выхода начинается только после принятия оффера;
- во всех 10 основных этапах есть блоки «Вход в процесс / Участники / Процесс завершён, когда»;
- содержательная часть адаптации не переписывалась, добавлена только процессная рамка.
