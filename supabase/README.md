# Supabase directory

This directory is intentionally ready for versioned Supabase work but contains no
linked project, credentials or production data.

- Put timestamped SQL migrations in `migrations/`.
- Add Supabase CLI configuration only after the owner confirms the development
  project.
- Follow `../docs/integrations/SUPABASE_SETUP.md` and `../AGENTS.md`.
- Never commit `.env`, database passwords, access tokens or secret/service-role keys.
